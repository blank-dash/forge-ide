# Forge dash v0.6.0

## Highlights
- Command palette, quick open, and symbol outline picker
- File search panel in the sidebar
- Workspace spending dashboard with recent usage history
- Checkpoints and review flow for safer agent edits
- Better session, task, terminal, and settings flows
- Expanded smoke coverage and regression tests

## Details
- Added quick navigation and picker overlays for files, commands, and symbols.
- Added workspace search across files.
- Added a dashboard spending chart and recent activity summary.
- Added checkpoints/review support for edits and safer workspace flows.
- Improved task handling, session management, and terminal integration.
- Expanded update and release plumbing for packaged builds.
- Added new tests for fuzzy matching, outline extraction, and shutdown behavior.

- `npm run typecheck`
- `npm run build`
